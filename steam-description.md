[h1]Description of Mod[/h1]
[b]Gear Up and Go Reforked[/b] adds a button that drafts a pawn, equips the gear for their current outfit, and sends them to a targeted location.

[h1]Features[/h1]
[list]
[*][b]Gear Up Command:[/b] Draft a pawn, equip the needed gear, and move them to the selected destination.
[*][b]Better Pawn Control Support:[/b] Uses the configured BPC policy name when the mod is installed.
[*][b]Outfit Stands Plus Support:[/b] Can work with outfit-stand gear flow when the integration is available.
[*][b]Defensive Positions Safety:[/b] Avoids interrupting active Defensive Positions gear or movement jobs.
[/list]

[h1]How to Use[/h1]
Set the Better Pawn Control policy name in the mod settings, then use the Gear Up And Go command in RimWorld.

[h1]Compatibilities[/h1]
[list]
[*][b]Supported RimWorld version:[/b] 1.6.
[*][b]Required mod:[/b] Harmony.
[*][b]Optional mod support:[/b] Better Pawn Control, Outfit Stands Plus Forked, and Defensive Positions Forked.
[*][b]Load order:[/b] Load after Harmony and any supported integration mods.
[/list]

[h1]Settings / Setup Instructions[/h1]
Open the mod settings window and enter the Better Pawn Control policy name you want the button to apply.
